# 客户分析=条件分析+意愿分析
【条件分析】参考维度：
1.公司/工厂实力：家庭作坊？中大型工厂？纯代加工，是否有业务开拓。。。
2.在1688平台上的状态：实商/超工，数字营销的消耗能力
3.客户行业：工业品，消费品都可以，零售类不太适合。

<!-- Slide number: 17 -->
【意愿分析】参考维度：
1.抖音发展的这5年里，这个客户布局了没；
2.客户是否有开启视频号？是否有过新媒体意识？
3.数字营销每月消耗多少
4.客户目前自己有没有用豆包，千问等，
5.对AI意识和认可度
6.有没有品宣意识

# 禁止服务的行业
1.  医疗健康类：包括但不限于医疗机构、医美机构、保健品、医疗器械、药品（含处方药、非处方药）、减肥产品、养生保健、丰胸/增高产品、宣称能根治疑难病症的相关行业及产品推广；
2.  金融投资类：包括但不限于网贷、虚拟货币、加密货币、股票配资、期货、外汇、非法集资、金融诈骗、无金融监管许可的理财产品推广等相关行业；
3.  违法违规类：包括但不限于赌博、色情、低俗内容、传销、诈骗、非法集资、恶意营销、网络诈骗等相关行业；
4.  国家管控类：包括但不限于烟草、电子烟、管制刀具、易燃易爆物品、毒品及相关衍生品、涉密信息相关行业；
5.  虚假误导类：包括但不限于虚假产品、虚假测评、恶意刷量、虚假宣传相关的行业及业务；
6.  其他违规行业：包括但不限于未取得相关资质的教育培训机构（尤其是K12学科类培训）、非法医美、违规金融中介、AI深度伪造相关违规业务；农药、兽药相关行业；违规食品、非法添加违禁成分的食品相关行业；风水占卜、算命改运等封建迷信相关行业。

所有商标词所有商标词都需提供商标证明，非自有品牌的要有代理品牌提供授权书
