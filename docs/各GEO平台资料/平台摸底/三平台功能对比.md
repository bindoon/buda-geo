# 三平台 GEO 后台功能对比（摸底摘要）

> 基于 2026-08-05 演示账号登录抓取。细节见各平台单独文档。

## 1. 一句话定位

| 平台 | 定位 |
|------|------|
| **大泽 GEO** | 关键词→写作→多通道发稿（门户媒体/自媒体/B2B/官网）+ 分模型收录报表；偏 1688/诚信通场景 |
| **摘星搜荐** | 「立身份→建资产→布信源→发全域→盯数据」全链路；智能体官网 + 媒体/平台双发布 + 短视频矩阵 |
| **掌心/荟信 Claw** | GEO 答案营销（备课/授课）+ Agent（官网/名片/数字员工）+ A2P 创意视频；算力值统一计量 |

## 3. 主路径对照（便于映射布达 Part A）

```text
共性流水线：
  身份/资质 → 知识库&关键词 → 提示词/场景 → 批量生成 → 多通道发布 → 收录/曝光报表

大泽：  关键词 → 图片 → 提示词 → 写作任务 → webmedia/自媒体/B2B → tongji
摘星：  立身份 → 建资产 → 布信源(创作+自动发布) → 发全域 → 盯数据
掌心：  知识库(画像/场景词) → 备课(图文/视频) → 授课(多信源训练) → 看板；旁路 Agent/A2P
```

## 4. 布达可借鉴优先级（建议）

1. **先对齐共性主路径**（知识库 + 关键词/问题 + 写文 + 发布 + 报表），与现有 `clean → diagnose → write → publish` 一致。
2. **发布通道分层**：自有站 / 媒体分发 / 自媒体；大泽的媒体筛选维度、摘星的日发布配额与状态机可参考。
3. **验收证据**：分模型收录 + 截图凭证（大泽已有「查询带截图」）；报表分享链接。
4. **差异化慎选**：数字员工/名片、短视频矩阵属于 Agent/A2P 扩展，可放 Part B，避免 Part A 范围膨胀。
5. **计量设计**：提前定「配额维度」（词数/篇数/通道/算力），三家模式都可对照报价方案。

> **已落入主方案（2026-08-05）**：见 [`布达-GEO工具详细解决方案.md`](../../布达-GEO工具详细解决方案.md) §0.1 — 法人证仅五大自媒体实名；年 1500 篇投三大权威信源 `social|media|b2b`；文章状态机、任务绑知识库、诊断凭证、manifest 配额；短视频/数字员工/爆文复刻仍后置。
