任务字段：任务名、蒸馏词、创作上限、已创作、是否引用知识库、状态。示例任务含「GEO下半年走势」「1688商家为什么要做GEO」「厨房家电」「玻璃贴膜」等；支持「引用知识库 / 未使用」。

### 网站媒体发布

媒体筛选维度丰富：

- **行业领域**：IT科技、财经商业、健康医疗、工业贸易等 20+ 类
- **综合门户**：腾讯/新浪/网易/搜狐/人民网/新华网等
- **地区 / 入口级别 / 收录承诺 / 链接类型 / 发稿速度**

偏「稿件分发 / 媒体投放」型 GEO，而非仅自有站点 SEO。

## 7. 对紫驰方案的启示

- **流程极清晰**：关键词 → 素材 → 指令 → 任务 → 多通道发布 → 收录报表，可直接对照 Part A 本地闭环。
- **发布通道是卖点**：网站媒体（门户/地方站）+ 自媒体 + B2B + 官网 SEO，比「只写文章」重。
- **计量模型**：关键词配额 + 写作篇数 + 发布次数 + 点数/余额双账户。
- **证据形态**：查询带截图、分模型收录大屏，适合对客验收。
