# measure-and-iterate — 复测与迭代

> 状态：占位，尚未实现周期任务与归因模型。

## 目标

发布后按周期复测 GEO 可见度，比较基线与后续结果，并把新缺口送回场景和内容规划。

## 计划流程

1. 固定平台、题集版本、时间窗口和指标口径，运行可比 probe。
2. 比较有效覆盖、品牌提及、主动推荐、竞品、负面风险和引用来源变化。
3. 区分“观察到变化”和“证明由某篇内容导致”，避免过度归因。
4. 生成新的 diagnosis gaps；需要新增或调整场景时回到场景库复核。
5. 退役无效任务，补强证据不足场景，形成下一轮 content plan。

不得直接修改已确认事实、诊断 run 或场景版本；所有变化创建新版本。
