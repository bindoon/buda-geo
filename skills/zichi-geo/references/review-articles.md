# review-articles — 人工审稿与批准

> 状态：占位，尚未实现统一命令与数据契约。

## 目标

在发布前检查事实、合规、重复度、渠道适配和配图授权，并记录可追溯的修改与批准状态。

## 计划流程

1. 校验正文引用的事实仍属于任务绑定的 confirmed snapshot。
2. 检查标题与正文是否夸大、重复、跑题或泄漏 restricted/internal 信息。
3. 检查医药等敏感行业表述、联系方式和图片使用范围。
4. 记录修改意见；修改后重新校验事实引用。
5. 将状态从 `draft` 置为 `pending_review`，人工批准后才置为 `approved`。

未批准文章不得排队或发布。这里的“批准”是稿件状态，不需要复用企业事实确认人字段。
