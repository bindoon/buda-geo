# export-platform-views — 三平台术语导出

> 状态：OpenSpec 已规划，尚未实现自动导出或平台提交。

## 目标

维护一份平台无关的客户问题与购买场景库，再按平台需要生成派生视图。平台术语不是企业事实，也不是场景库的主模型。

## 前置条件

- 已确认 scenario library version
- 只使用 `public` 且经批准的事实、证据和转化动作

## 三平台映射

| 通用场景内容 | 大泽导出 | 摘星导出 | 掌心/荟信导出 |
|---|---|---|---|
| 主产品/业务名称 | 产品或业务关键词 | 关键词训练组 | 公司介绍引用 |
| 代表性客户问题 | 写作问题 | 训练问法 | 搜索词场景、问答词场景 |
| 经批准的下一步行动 | 需要时随任务携带 | 转化目标 | 画像/场景配置中的公开行动 |

“跟词”若出现在平台材料中，统一按“与核心产品/业务关联的扩展词或问法”理解，不作为通用 Schema 字段。

## 计划流程

1. 读取已确认场景及代表问题。
2. 按 adapter version 生成平台视图，并保留 canonical scenario/question IDs。
3. 校验不包含密码、Token、身份证、restricted/internal 证据或无事实支持的宣传。
4. 首版只落本地 JSON/可读文件，不自动登录或提交第三方平台。

编辑平台导出不能静默改写通用场景；需要回到场景库显式协调。
