# 运营汇报模板（clean 完成后必用）

> **读者**：不懂代码的运营/商务。汇报时**禁止**堆 JSON、字段名、命令行；技术细节放文末「附录（可选）」或省略。

## 必须遵守

1. 先写 **一句话结论**（能不能进入下一步）
2. 再写 **资料放哪了**（文件夹用中文说明用途）
3. 再写 **整理出了什么**（用业务语言，不用 A/B/C/D 字母也可，若用则括号解释）
4. 再写 **还缺什么 / 您要做什么**（可操作，不说 `recommend`/`block` 英文）
5. 最后 **请您确认**（一句问话）

**不要**在正文出现：`app_id`、`validate OK`、`clean_ready`、`manifest.gates`、`conversion.shop_url`、`.json` 文件名（除非对方明确要求看文件）。

**结论**：{✅ 可以进入「AI 诊断/写文」 / ⚠️ 还有必补项，暂不能下一步}

## 整理后的成果（系统已生成，供后续写文用）

都在文件夹：**`projects/{目录名}/`** 下：

| 位置 | 是什么 | 您需要做什么 |
|------|--------|--------------|
| **`knowledge/`** | 结构化「公司档案」（机器可读，共 7 份） | 一般不用手改；缺项补资料后让我们再跑一轮清洗 |
| **`assets/images/`** | 产品图、工厂图（从 inputs 复制整理） | 可在 Finder 里打开查看；缺图可补到 inputs 再清洗 |
| **`manifest.json`** | 本项目的进度单（缺啥、能否下一步） | 不用打开；看本汇报即可 |

### 档案里有什么（用人话）

- **公司基本信息**：{公司全称}、联系人 {姓名}、{地区}、1688/官网链接 {有/无}
- **公司介绍**：已从知识库 Word 提取，约 {N} 字
- **产品与图片**：共 **{N} 个产品/条目**，**{N} 张图片** 已归类
  - 举例：{产品1}、{产品2}…
  - 工厂/车间图：{N} 张
- **搜索词与问题**：主搜索词 **{N}** 个；用户问题 **{N}** 条（来自词表）
- **常见问答（FAQ）**：{暂无 / 已有 N 条}
- **写文任务草稿**：已按主词预生成 **{N}** 条写作方向（待诊断/写文阶段使用）

### 安全说明（必提一句）

- 收集表里的**平台登录密码**已从档案中移除，不会写进知识库；账号名保留。
- 密码请单独保管（本地 `.secrets.env`，勿发群里）。

## 还缺什么（不影响 / 建议补 / 必须补）

用下表，**不要写英文 code**：

| 类型 | 说明 | 您可以 |
|------|------|--------|
| {建议补充} | {如：没有客服聊天记录，FAQ 会偏空} | 把聊天记录导出放到 `inputs/chat/` 文件夹，再说一声「重跑清洗」 |
| {建议补充} | {如：密码已从档案剥离} | 无需操作，密码单独保管即可 |
| {可选} | {如：身份证已忽略} | 无需操作 |
| {必须补 — 仅有 block 时} | {具体缺什么} | {具体怎么补} |

## 术语翻译表（内部 → 对外）

| 内部 | 对运营说 |
|------|----------|
| clean / 清洗 | **资料整理**（把 Excel/Word/图片变成标准档案） |
| validate | **检查通过**（格式与链接无误） |
| clean_ready | **可以进入下一步** |
| block | **必须补** |
| recommend | **建议补**（不挡下一步） |
| optional | **可选** |
| gates.clean pending | **整理完成，等您点头确认** |
| gates.clean confirmed | **您已确认，可诊断/写文** |
| SKU | **产品/条目** |
| generation_plan | **写文任务草稿** |
| chat_logs | **客服/询盘聊天记录** |
| secrets_stripped | **密码已从档案移除** |
| legal_id_ignored | **身份证已跳过** |
| inputs/ | **您提供的原件文件夹** |
| knowledge/ | **整理后的公司档案** |
| assets/images/ | **整理后的图片** |
