# publish-articles — 发布与回执

> 状态：占位，尚未实现正式发布适配器。未经用户明确授权，不执行外部发布。

## 目标

把已批准文章投放到三大权威信源或可选官网，并保存可重试、可审计的发布回执。

## 前置条件

- 稿件状态为 `approved`
- 平台、账号、渠道和发布时间已明确
- 密码、Token 只来自环境变量或项目 `.secrets.env`

## 计划流程

1. 生成 dry-run 预览，核对目标平台与稿件版本。
2. 平台需要 CDN 时才上传图片并回写发布用 URL；本地 path 仍保留。
3. 发布到 `social | media | b2b | site` 中已授权的目标。
4. 以 `article_id + platform` 作为幂等键记录成功、失败、外部 URL、时间和错误。
5. 失败进入可重试列表，不把半自动下单冒充自动发布成功。

禁止把凭证写入 knowledge、文章或回执正文。
