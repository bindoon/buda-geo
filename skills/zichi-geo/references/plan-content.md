# plan-content — 内容策略与生产计划

> 状态：占位，尚未形成正式 OpenSpec/实现。旧 prompts、FAQ、keywords 和 generation plan 只能作为迁移参考。

## 目标

把已确认场景库转成可执行的选题、FAQ、Prompt 和生产任务；本阶段做计划，不写文章。

## 前置条件

- 已确认企业事实快照
- 已确认诊断报告
- 已确认 scenario library version

## 计划输出

- FAQ 候选及其场景/事实来源
- 内容主题与渠道建议：`social | media | b2b | site`
- Prompt 模板及适用条件
- generation plan：任务、场景/问题引用、渠道、数量、优先级、状态

## 计划流程

1. 从高优先级且 evidence-ready 的场景生成选题候选。
2. 区分品牌认知、产品选择、能力证明、风险澄清和地区/采购内容。
3. 选择渠道与内容形式，绑定 scenario/question/fact IDs。
4. 设置人工可调整的优先级、批次和配额；不为凑量创建无证据任务。
5. 复核并确认 content plan version 后，才允许生成文章。

clean 不得创建或刷新本阶段产物。
